# Безопасность

Программа работает локально. Единственное обращение к сети — проверка обновлений (запрос к api.github.com раз в сутки, отключается в меню «Обновления»). Ваши файлы, индекс и пути никуда не отправляются. Установщик обновления скачивается только по HTTPS с доменов GitHub и запускается, только если его SHA-256 совпал с `SHA256SUMS.txt` из того же релиза. О найденных уязвимостях сообщайте через вкладку
**Security** репозитория (Report a vulnerability) или в Issues, если проблема не критична.
Скачивайте программу только со страницы **Releases** этого репозитория и сверяйте SHA-256 из `SHA256SUMS.txt`:

```
Get-FileHash .\FilePilotSetup-0.5.0.exe -Algorithm SHA256
```
