# История изменений

## 0.8.0
- Оператор `newer:7` в строке поиска: только файлы, изменённые за последние 7 дней (парный к `older:`).
- Оператор `name:счёт` ищет только в имени файла, а не в содержимом: `name:счёт ext:pdf`.
- Результаты поиска сортируются кликом по заголовку колонки (путь, размер, дата): по возрастанию, по убыванию, снова по релевантности. Выбор сохраняется между поисками.
- Кнопка «Сжать индекс» (и команда `filepilot optimize`): индекс сжимается, свободное место возвращается диску. Размер индекса виден в строке состояния и в `filepilot stats`.

## 0.7.0
- Индексация целого диска стала безопасной и быстрее: системные папки в корне диска (Windows, Program Files, ProgramData, корзина) и AppData пропускаются, папки-junction не обходятся, заглушки облака (OneDrive и др.) не читаются, чтобы не запускать скачивание файлов.
- Обход папок ускорен: размер и даты берутся прямо из обхода без лишних обращений к диску (50 000 файлов обходятся за доли секунды). Счётчик прогресса больше не заваливает интерфейс, при повторной индексации показывается процент по прошлому проходу.
- Индексация идёт с пониженным приоритетом, компьютер не тормозит.
- При добавлении диска целиком программа предупреждает, сколько это займёт, и спрашивает подтверждение.

## 0.6.0
- Операторы в строке поиска: `ext:pdf,docx`, `in:"C:\Папка"`, `older:30`, `bigger:5mb`, `smaller:100kb`. Они сильнее панели «Фильтры»; фраза в кавычках ищется как есть. Работают и в консоли.
- История запросов: Enter или «Найти» запоминает запрос (последние 20), подсказки появляются при наборе.
- Папки перетаскиваются из Проводника прямо в окно программы: они добавляются в индекс, и индексация начинается сама.
- Экспорт в CSV для списка дубликатов и таблицы карты диска (Excel открывает файл сразу, кодировка UTF-8 с BOM, разделитель `;`).
- README: установка и быстрый старт идут первыми, запуск из исходников, консольные команды и сборка вынесены в раздел «Для разработчиков».

## 0.5.0
- Исключения индексации: в окне «Папки» можно исключить папку целиком или маску имени (`node_modules`, `*.tmp`, `~$*`). Уже проиндексированные файлы из исключённых мест убираются из индекса при следующей индексации. В консоли: `filepilot exclude add|remove|list`.
- Поиск в выбранной папке: в панели «Фильтры» появился список «Папка» (по умолчанию «Все папки»). Выбор сохраняется в сохранённых поисках. В консоли: `filepilot search ... --folder <путь>`.

## 0.4.2
- Постоянная ссылка на установщик: `FilePilotSetup.exe` (рядом с версионным файлом), её используют кнопки «Скачать» на сайте и в README.
- Окно «О программе» (меню «Обновления»): версия, ссылки на сайт, установщик и исходный код.
- Новое описание и скриншоты на русском и английском (README.md, README.en.md), скрипт `scripts/make_screenshots.py`.
- Окно пробного запуска правил: колонки подгоняются под содержимое.

## 0.4.1
- Уведомление об обновлении: после установки новой версии (автообновление или установщик, скачанный заново) программа показывает уведомление Windows и окно «Что нового» с описанием изменений. При первой установке и при повторной установке той же версии ничего не показывается.

## 0.4.0
- Дубликаты: можно выбрать, какую копию оставить (первую в списке, самую старую, самую новую или с самым коротким путём), и отметить остальные одним нажатием.
- Фоновое обновление индекса: меню «Фоновое обновление» (выкл., каждые 15 минут, каждый час, каждые 6 часов), пока программа открыта.

## 0.3.1
- Карта диска: кольцевая диаграмма по типам файлов и по папкам (крупные сектора, «Прочее», подсказка при наведении).
- Исправлено: подписи «(файлы в корне)» и «(без расширения)» не переводились на английский.
- Битые PDF больше не сыплют предупреждения в консоль.

## 0.3.0
- Новый установщик: окно с картинкой и настоящей иконкой, русский и английский язык по системе, чистая замена файлов при обновлении, при удалении спрашивает, стирать ли индекс и настройки.
- Обновления: программа раз в сутки спрашивает GitHub о новой версии (можно отключить в меню «Обновления»), показывает «Что нового», скачивает установщик, сверяет SHA-256 с `SHA256SUMS.txt` и ставит поверх. Портативная версия только открывает страницу релиза.
- Интерфейс на английском и русском: язык выбирается автоматически по системе или кнопкой «Language / Язык» (после смены нужен перезапуск). Консольные сообщения пока только на русском.
- Поиск: панель предпросмотра с подсветкой найденных слов (текст берётся из индекса).
- Поиск: сохранённые поиски (запрос и фильтры) и экспорт результатов в CSV для Excel.

## 0.2.0
Программа написана заново.

- Новый русский интерфейс с тёмной темой, горячие клавиши, окна «Папки» и «Правило».
- Поиск: префиксы («догов» найдёт «договор»), точные фразы в кавычках, живой поиск при вводе, фильтры по расширению, размеру и возрасту.
- Индексация в фоне с отменой; из индекса автоматически убираются удалённые файлы; повторный проход почти мгновенный.
- Чтение docx, xlsx, pptx, odt/ods/odp без сторонних библиотек; корректное определение кодировки cp1251.
- Дубликаты и правила работают только через корзину; окончательное удаление убрано.
- Исправлено: при совпадении имён перенос файла мог не сработать, теперь чужие файлы не затираются (`report (1).pdf`).
- Безопасность: текст из файлов в результатах поиска экранируется и не может подмешать HTML.
- Консольная версия: `python -m filepilot --help`.
- Тесты и автоматическая проверка на GitHub.
