# История изменений

## 0.3.1
- Карта диска: кольцевая диаграмма по типам файлов и по папкам (крупные сектора, «Прочее», подсказка при наведении).
- Исправлено: подписи «(файлы в корне)» и «(без расширения)» не переводились на английский.
- Битые PDF больше не сыплют предупреждения в консоль.

## 0.3.0
- Новый установщик: окно с картинкой и настоящей иконкой, русский и английский язык по системе, чистая замена файлов при обновлении, при удалении спрашивает, стирать ли индекс и настройки.
- Обновления: программа раз в сутки спрашивает GitHub о новой версии (можно отключить в меню «Обновления»), показывает «Что нового», скачивает установщик, сверяет SHA-256 с `SHA256SUMS.txt` и ставит поверх. Портативная версия только открывает страницу релиза.
- Интерфейс на английском и русском: язык выбирается автоматически по системе или кнопкой «Language / Язык» (после смены нужен перезапуск). Консольные сообщения пока только на русском.
- Поиск: панель предпросмотра с подсветкой найденных слов (текст берётся из индекса).
- Поиск: сохранённые поиски (запрос и фильтры) и экспорт результатов в CSV для Excel.

## 0.2.0
Программа написана заново.

- Новый русский интерфейс с тёмной темой, горячие клавиши, окна «Папки» и «Правило».
- Поиск: префиксы («догов» найдёт «договор»), точные фразы в кавычках, живой поиск при вводе, фильтры по расширению, размеру и возрасту.
- Индексация в фоне с отменой; из индекса автоматически убираются удалённые файлы; повторный проход почти мгновенный.
- Чтение docx, xlsx, pptx, odt/ods/odp без сторонних библиотек; корректное определение кодировки cp1251.
- Дубликаты и правила работают только через корзину; окончательное удаление убрано.
- Исправлено: при совпадении имён перенос файла мог не сработать, теперь чужие файлы не затираются (`report (1).pdf`).
- Безопасность: текст из файлов в результатах поиска экранируется и не может подмешать HTML.
- Консольная версия: `python -m filepilot --help`.
- Тесты и автоматическая проверка на GitHub.
